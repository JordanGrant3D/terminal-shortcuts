# Terminal Shortcuts
Stack is a simple system to make and run shortcuts in terminal, all you do is inside your project add folder called "tshort"
and create a python file with the name of your shortcut for example "run.py"


Then run tshort from inside your project directory, and type _l to see all avaliable shortcuts and _h for help.


To install just run:



```
pipx install git+https://github.com/JordanGrant3D/terminal-shortcuts.git

```
To uninstall just run:

```

pipx uninstall terminal-shortcuts
```
