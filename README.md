# Terminal Shortcuts
Stack is a simple system to make and run shortcuts in terminal, all you do is inside your project add folder called "tshort"
and create a python file with the name of your shortcut for example "run.py"


Then run tshort from inside your project directory, and type _l to see all avaliable shortcuts.


To install just run:



```
bash <(curl -fsSL https://raw.githubusercontent.com/JordanGrant3D/terminal-shortcuts/refs/heads/master/install.sh)

```
To uninstall just run:

```

bash <(curl -fsSL https://raw.githubusercontent.com/JordanGrant3D/terminal-shortcuts/refs/heads/master/uninstall.sh)
```
